Architecture
System Design
MODULE_01
Face Detection
OpenCV Haar Cascade + DNN face detection. Multi-scale detection at 15fps. Bounding box extraction for recognition pipeline.
MODULE_02
DeepFace Recognition
ArcFace model for 512-dim face embeddings. Cosine similarity matching against enrolled face database. Threshold at 0.4.
MODULE_03
Anti-Spoofing
Passive liveness detection using depth maps and texture analysis. Rejects photo, video, and 3D mask spoofing attempts.
MODULE_04
Attendance Engine
Real-time logging with timestamp and confidence score. Duplicate detection prevents double-marking. Session management.
MODULE_05
Google Sheets Sync
OAuth2 Sheets API integration. Auto-pushes attendance data. Auto-generates daily reports and absence notifications.
MODULE_06
Flask Dashboard
Real-time attendance monitor. Admin controls for enrollment. Statistics dashboard with attendance trends and export.
