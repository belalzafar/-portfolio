Architecture
How It Works
01 · INPUT
Image Preprocessing
Resize to 224×224px. Augmentation: rotation, flip, zoom, brightness on 87K PlantVillage images.
02 · MODEL
EfficientNet-B3 CNN
Transfer learning on pretrained EfficientNet-B3. Fine-tuned with dropout 0.3. Custom classification head for 38 classes.
03 · OUTPUT
Prediction Engine
Softmax across 38 disease classes. Confidence threshold 60%. Mapped to treatment database.
04 · API
Flask REST Backend
TensorFlow SavedModel via Flask. OpenCV preprocessing. Deployed on Google Cloud Run. <2s latency.
05 · UI
React Dashboard
Drag-and-drop upload, disease history log, treatment library, offline PWA for rural connectivity.
06 · RESULTS
94.2% Accuracy
AUC-ROC 0.98. +6.4% over baseline VGG16. Validated on real farm images across 3 locations in UP.
